
 A portfolio-level AI project designed to help beginner programmers understand programming errors instead of blindly copying AI-generated fixes.

## Project Goal

Build an AI-powered debugging tutor that guides beginners from:

**Error → Understanding → Hint → Attempt → Feedback → Fix**

The core idea is to use AI as a **teacher**, not just an automatic code-fixing machine.

## Project Workflow

1. Define the problem
2. Research existing solutions
3. Talk to target users
4. Define the MVP
5. Design the user experience
6. Design the technical architecture
7. Build V1
8. Test
9. Evaluate
10. Improve
11. Deploy
12. Document the process

## Problem

Beginner programmers often encounter compiler and runtime errors that they do not understand. Many use AI tools by copying their code and error message and asking for a direct fix. This can solve the immediate problem without helping them understand the cause of the error or develop debugging skills.

## Target User

Beginner coders using java/python.
Second‑year student starting DSA
Self‑learner from non‑CS branch


## User Pain Points

- Cryptic error messages in terminal
- Copy-paste → full fix habit
- Logic vs syntax confusion

## Problem Hypothesis

If an AI assistant provides guided explanations and progressive hints instead of immediately giving the corrected code, beginners may develop a better understanding of programming errors.

## Why This Problem Matters

this product is to help people just starting out in code to understand what they code and apply it. it will help build the base and the foundation for DSA.
